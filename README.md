# Mao — обновления приложения

Приложение **Mao** (изучение китайских иероглифов) само проверяет этот репозиторий при каждом запуске.

| Файл | Что это |
|---|---|
| `update.json` | номер последней версии экранов (`web`) и приложения (`app`) |
| `web/` | экраны приложения. Обновляются на телефоне незаметно: скачиваются только изменённые файлы, проверка SHA-256 |
| `apk/Mao.apk` | установочный файл. Телефон предлагает «Доступна версия X · Обновить» |
| `tools/publish.py` | как публикуется обновление |

Файлы раздаются через jsDelivr (`cdn.jsdelivr.net/gh/sanctumares1-svg/mao@<тег>/…`), запасной путь — сам GitHub.
Файлы каждой версии берутся по коммиту, на который указывает `update.json`.

**Ключ подписи APK здесь не хранится** — он у владельца. Без него обновление APK не установится поверх старого.
